# winding

导出 / 读入两侧的绕向校验与往返实验。`make test` 跑自检并把九项指标写到
`../artifacts/winding_obj/`（TSV + JSON + OBJ + 完整日志）。

## 复现的故障

导出器先做一次固定种子的顶点重排（Fisher–Yates），再把每个三角面的三个
索引**规范化成升序**。升序排列相对原绕向是奇排列还是偶排列完全决定该面
是否翻转：奇排列翻转。三个模型都恰好有一半面是奇排列，于是重读后原始
面法线一致率正好 `0.5000`。

## 两侧同一个 `winding_check()`

1. **共享边一致性（BFS）**：闭合流形的每条边恰由两个面共享，且两面必须
   以相反方向遍历该边。从一个种子面扩散，纠正所有被单独打乱的面。
   全局投票只能决定整体符号，无法定位“一半面反了”，定位靠这一步。
2. **面积加权投票定整体朝向**：参考方向 `r` 取包围盒最大跨度主轴的
   `+世界轴` 方向。每面以叉积模长（=2 倍面积）为权重，按 `n·r` 正负投
   `W+ / W−`，`|n·r| < 0.05` 的近轴垂面弃权。

票差比例：

```
margin = |W+ − W−| / (W+ + W−)      # 只计有效票
```

另记录 `margin_all = |W+ − W−| / 总面积`（含弃权面）。`margin < 0.05`
判为**接近平局**。

## 三个模型，三组九个数

| 模型 | 最大主轴 | 票差比例 margin | 翻转面数 | 往返后法线一致率 |
|---|---|---:|---:|---:|
| `rocket` 长火箭 | x | **0.4858** | **80** / 160 | **1.0000** |
| `pear` 不对称梨（轴转到 z） | z | **0.1193** | **120** / 240 | **1.0000** |
| `egg` 近对称蛋（轴转到 y） | y | **0.0196** ⚠接近平局 | **220** / 440 | **1.0000** |

“翻转面数”是读入侧校验实际翻回的面数，与导出器奇排列真值逐面一致
（`*_flip_mask_matches_exporter=1`）。一致率按面积加权顶点法线、最近位置
匹配顶点、`dot ≥ 0.99` 统计；修正后面法线一致率与平均点积也都是 `1.0000`。
未校验直接重读时三个模型都是 `0.5000`。

## 为什么最大主轴能避免对称平局

三个模型都是绕自身长轴的旋转体。对旋转体而言，沿任意**横轴**投票都会被
旋转对称性精确抵消（实测票差 `≈ 1e-16`）；只有沿包围盒最大跨度的长轴，
端面积/锥度不对称才能给出非零票差：

```
rocket: x=0.485847  y≈0  z≈0   (major=x)
pear:   x≈0         y≈0  z=0.119345 (major=z)
egg:    x≈0         y=0.019626 z≈0   (major=y)
```

## 接近平局时的并列诊断（egg）

蛋的票差只有 1.96%，低于 5% 阈值，程序输出一行 `TIE_DIAG`，把主轴与法线
分布的方向散布（面积加权二阶矩 `ΣA n nᵀ / ΣA` 的特征值/主特征向量）并列：

```
major_axis=y dir=(0,1,0) extent=2.240 | vote_margin=0.0196
alt_axis_margins=(6.69e-17, 0) |
normal_dispersion eval=(0.3538,0.3538,0.2924)
principal_normal_axis=(0,0,1) q_axis=0.2924
```

特征值接近 `(1/3,1/3,1/3)` 说明法线方向近各向同性散布，没有稳定的极性；
长轴票差微弱来自 `r(φ)=sinφ·(1+0.04 cosφ)` 的轻微端部不对称。此时投票的
**整体符号不可信**——本次固定种子的确定性构建恰好落在朝外一侧并恢复
`1.0000`，但接近平局时生产流程应改用有符号体积/质心射线，或直接携带导出
侧的投票证书，而不是采纳这一符号。
