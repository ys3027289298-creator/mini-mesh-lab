# attrmap

重拓扑后的顶点属性搬运：三角形面级最近点 + 重心坐标插值，附属性差统计与退化映射占比。

`make test` 跑自检并输出三档面数比（4× / 16× / 64×）的九项实验数据。

- 最近点扫描每个三角形（Ericson 区域分解），不是最近顶点。
- 搜索容差 `tol = h/√3 + eps_target`，`h` 为三角形最长边（面片尺寸），`eps_target=1e-3` 为目标几何误差；`1/√3` 是三角形顶点覆盖半径上界。
- 判据一：逐个原模型顶点，在新模型面上用重心坐标采样已搬运属性，统计 RGB 欧氏差的最大值与平均值。
- 判据二：最大重心权重 `≥ 0.9` 的映射记为退化成最近顶点，统计其顶点占比。

实验结论与九个数见 [RESULTS.md](RESULTS.md)。
