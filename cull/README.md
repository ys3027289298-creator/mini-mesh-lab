# cull

视锥剔除分层深度实验：胖包围球 → AABB 精确测试 → 空间四叉树 + 自适应盒粒度。

`make test`（或 `make && ./cull`）跑自检和三档实例数基准，输出：

- 12 项正确性自检（平面测试、SAT 真值、楔形误判样例、粒度单调性）；
- 胖球（半径=最长边）基线的提交数/漏剔/耗时；
- 粒度 `g=0..2` 的成本函数 `C(g)`、节省函数 `S(g)`、边际交点与盈亏平衡
  单提交成本，以及交换系数 `k` 的敏感性；
- 空间深度 `H=0..5` 的测试计数与耗时；
- 三档（200/400/800 实例）各自的 **提交数、剔除耗时、漏剔数、实际分层深度**；
- 深度/耗时比率并列，以及浅 `H=0` “退化成逐个精确测试”对照表；
- 末尾 `TWELVE:` 行即三组十二个数，`METRICS_JSON:` 为机器可读结果。

## 模型

- 视锥在观察空间解析给出 6 个归一化平面；场景用固定随机种子生成，可复现。
- 每实例 64 个提交单元；盒树粒度 `g` 对应 `1 / 8 / 64` 个子盒。
- 自适应粒度：`g = clamp(ceil(log2(D / (2·δ))))`，`D` 为盒子对角线，
  `δ` 为盒心到最近视锥面的距离。
- 漏剔真值由 SAT（AABB vs 视锥 45 条候选轴）逐叶子判定。
- 成本/节省交点：边际精确测试成本 `dC` 与边际少提交的时间价值
  `dS = Δsubs·k` 相等处；默认 `k=80 ns/提交`，可用
  `-DK_NS_PER_SUBMIT=...` 覆盖，程序另给盈亏平衡阈值与敏感性。

计时用 `CLOCK_MONOTONIC`、多批重复取最小值；共享/高负载机器上耗时会有
抖动，但提交数、漏剔数、深度均为确定性结果。
