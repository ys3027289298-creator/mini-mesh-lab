# normal

`make test` 跑自检。

增量更新的影响边界分两层：

1. 固定法线分组时，移动顶点 `v` 只会改变其邻接面的面法线，因此脏顶点集合就是这些面的全部角点，即拓扑一环。
2. 如果多个顶点共享一个法线分组，一环角点所属分组的所有成员都要重算；若移动还触发重新分组，则旧分组和新分组的成员都要纳入闭包。只更新拓扑一环会漏掉远处的同组顶点。

自检中的 `counterexample_one_ring_misses_spread=1` 会固定这个反例：顶点 0 移到远处顶点 6 的位置并与其合并法线组；朴素一环更新后顶点 6 仍是旧法线，而全量结果已经改变。`incremental_grouped_matches_full=1` 验证分组闭包更新与全量重算一致。
