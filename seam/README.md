# seam

UV 接缝法线合并实验。`make test` 跑自检，`make run` 跑完整实验，产物在
`../artifacts/seam/`。

## 问题

UV 接缝把同一个世界位置拆成两条顶点记录，各自累加面积加权法线，渲染时
接缝两侧插值不连续，出现一条亮线。按位置容差 ε 合并不难，难在定 ε：

- 太松，真正的折边两侧顶点也被并进同一法线组，硬转折被抹平；
- 太紧，接缝孪生顶点合不上，亮线保留。

## 方法

### 1. 容差对面片尺寸的依赖

绝对容差随模型尺度变化，因此用无量纲容差

```
k = ε / L,   L = 网格边长中位数（面片特征尺寸）
```

实验在 `scale = 0.5 / 1.0 / 2.0` 三档下各跑一次，`scale.csv` 显示每档模型
的 `k_seam`（合上全部接缝所需的最大 k）与 `k_crease`（第一条折边被误合时
的最小 k）在三个尺度下完全相同，只有 L 随尺度线性变化——这就是容差对
面片尺寸的依赖关系：固定 k，ε 随 L 缩放。

### 2. 容差对误合并折边数的影响

`fig_tolerance_curves.png` 把两条曲线画在一起：

- 未合缝对数随 k 单调下降，在 `k_seam` 处降到 0；
- 误合并折边对在 `k_crease` 之前恒为 0，之后阶跃上升。

安全窗口是 `(k_seam, k_crease)`。工作点取二者几何平均

```
k* = sqrt(k_seam · k_crease)
```

窗口中心，对阈值估计误差最不敏感。本几何下三档模型的窗口约为
0.019–0.155，k* ≈ 0.054–0.063。

### 3. 角度保护

位置容差无法区分"近但属于折边"的点。`weld_guarded` 在位置判据之外加
法线锥：两条记录的逐顶点法线夹角超过 30° 就拒绝合并。`fig_error_curves.png`
显示在 k > k_crease 后，纯位置焊接的误合并数升到 75、平均法线误差冲到
18.5°，而保护焊接始终 0 误合并、误差 ≤1.1°。

### 4. 打通 UV 通道

位置焊接只把记录并入同一个并查集组，不改变每条记录自带的法线。
`share_group_normals` 把每组的单位法线累加平均后写回组内所有记录——这一步
才真正"打通通道"，让接缝两侧共享一条法线。只做位置匹配时：

- 位置并查集已合并（`position_open_pairs = 0`）；
- 但接缝孪生顶点仍各持各的法线（`unmerged_vertices` 非零，
  每组不同法线数等于记录数）。

## 测试几何

`mesh_build_folded_strip` 生成 4 块交替倾斜的面板（折边，~70° 法线夹角），
面板是带正弦弯曲的平滑曲面；按 `nseam` 在面板内部网格线处切出 UV 岛，
接缝孪生顶点沿曲面切向错开 `0.02 · cell`，折边相邻顶点错开 `0.2 · cell`。
每个 UV 岛段独立分配顶点，所以岛间只共享世界位置、从不共享索引，
UV 通道数恒为 `4 + nseam`。

三档密度：sparse=2 条接缝、medium=7 条、dense=14 条。

## 三组十二个数

单位尺度、k=k* 下，每档四个指标（完整数据见 `summary.csv`）：

| 密度 | 未合并顶点 | 误合并折边对 | 亮线像素 | 法线误差(°) |
|---|---:|---:|---:|---:|
| sparse (2)  | 0 | 0 | 0 | 0.1834 |
| medium (7)  | 0 | 0 | 1768 | 0.1649 |
| dense (14)  | 0 | 0 | 2357 | 0.1623 |

对照：只做位置匹配、不打通通道时

| 密度 | 未合并顶点 | 亮线像素 | 法线误差(°) |
|---|---:|---:|---:|
| sparse | 100 | 787 | 0.2476 |
| medium | 350 | 4127 | 0.5398 |
| dense  | 700 | 7857 | 0.8019 |

最密组合并后仍有 2357 亮线像素。通道并列（`fig_channels.png`）说明这不是
法线没打通：未合并顶点已为 0，每组不同法线数从 1250 降到 900（= 无接缝
基网格的顶点数）。残余像素来自接缝孪生记录之间 0.0025 单位的物理间隙在
屏幕上的亚像素投影，属于位置间隙而非法线分裂；法线驱动的亮线分量已被
消除（7857 → 2357，降 70%）。

| 密度 | UV 岛数 | 法线通道数(仅位置匹配) | 法线通道数(打通后) | 未合并顶点 |
|---|---:|---:|---:|---:|
| sparse | 6  | 950  | 900 | 100 → 0 |
| medium | 11 | 1075 | 900 | 350 → 0 |
| dense  | 18 | 1250 | 900 | 700 → 0 |
