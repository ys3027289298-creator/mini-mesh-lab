# seam

把美术验收「倒角处的光照过渡要看不出接缝」翻译成可量化的代理指标，并拿它卡
`normal/` 的面积加权顶点法线实现。`make test` 复现全部数值。

## 测试网格

沿截面轮廓挤出的长条（z 向长度 1，每段两个三角形）：

- 平面 1：y = 0，长 2；
- 倒角：圆心 (0,1)、半径 r = 1 的四分之一圆，N = 8 段，角度范围 −90°→0°，
  与两个平面**相切**（接缝处真实法线梯度为零）；
- 平面 2：x = 1，长 2。

两种细分：等角度（uniform8）和二次角度拥挤（nonuniform8，模拟 DCC 里常见的
不均匀倒角）。三个对比方案：

| 方案 | 接缝节点法线 |
|---|---|
| `flat` | 面法线硬着色（C0 接缝） |
| `area(current)` | 直接调生产代码 `normal/src/normal.c` 的面积加权 `vertex_normals()`（文字化 include 同一个 .c，不是另抄一份） |
| `fixed` | 弧上节点用解析径向法线，平面用法面；相切保证接缝节点两者一致 |

## 指标 A（主闸门）：接缝法线梯度跳变残差 NGJres

沿采样线（弧长 s，长度以 r 归一）在轮廓节点上估计法线的一阶差分：

```
g_i = (N_{i+1} - N_i)/h_i - (N_i - N_{i-1})/h_{i-1}     （法线梯度的跳变，单位 1/r）
NGJres = max_{i ∈ 接缝} max(0, |g_i| - |g_ref_i|)
```

**为什么对应「看不出接缝」**：Lambert 着色的亮度是 N·l，沿曲面的亮度一阶导
含 N 的一阶导（梯度），所以人眼感知到的"线条"不是法线本身不连续（C1 平滑
也会有），而是**亮度曲线在接缝处出现不该有的弯折**，即法线梯度的跳变。
`g_ref` 是该倒角设计上应有的梯度（圆的恒定曲率），残差只统计接缝处超出设计
曲率的部分——真正的光滑圆角因此不被误报。

辅助量：

- `hardgap`：接缝两侧法线夹角（只对硬着色有值，量 C0 级断裂）；
- `rawD2seam`：**不减参考场的原始二阶差分**，用来证明朴素做法会误报——
  fixed 方案在正确的圆上 rawD2 ≈ 1.0（就是曲率 1/r 本身），永远不可能归零；
- `devRMS`：节点法线相对参考场的 RMS 偏差（诊断用，不做闸门，因为它不区分
  偏差是集中在接缝还是均匀摊开）。

建议闸门（起始值，需用主观打分实验校准）：**NGJres ≤ 0.1 /r**。

## 指标 B（佐证，不做闸门）：亮度曲线拐点能量残差 LCEres

固定一盏方向灯 l，节点亮度 L_i = max(0, N_i·l)，逐段算亮度斜率，节点 i 的
拐点能量 E_i = |slope_i − slope_{i−1}| · min(h)，即一个采样段内的满量程
亮度变化分数（≈ Weber 分数）。闸门量同样是残差 E_i − E_ref_i，
`corners` = 残差 > 0.01（约 1 JND）的节点数。B0 是硬着色的 C0 亮度跳变。

它直接就是题目里说的「沿采样线亮度曲线拐点数」，但只能佐证 A，原因见下。

## 结果（卡之前 vs 卡之后）

`make test` 的完整输出，闸门 NGJres ≤ 0.1/r、LCEres ≤ 0.01：

### uniform8（等角度 8 段）

| 方案 | NGJres | rawD2（朴素二阶差分会误报） | hardgap | devRMS | corners | LCEres | B0 跳变 |
|---|---|---|---|---|---|---|---|
| flat | 0.4997 | 0.9515 | 0.0981 | 0.0865 | 3 | 0.0380 | 0.1309 |
| **area（现有实现）** | **0.4906** | 0.9424 | 0 | 0.0295 | 1 | **0.0536** | — |
| fixed | 0.0000 | 1.0000 | 0 | 0.0000 | 0 | 0.0000 | — |

### nonuniform8（二次拥挤 8 段）

| 方案 | NGJres | rawD2 | hardgap | devRMS | corners | LCEres | B0 跳变 |
|---|---|---|---|---|---|---|---|
| flat | 1.4998 | 1.9937 | 0.1838 | 0.1065 | 3 | 0.0208 | 0.1849 |
| **area（现有实现）** | **1.4555** | 1.9494 | 0 | 0.0235 | 1 | 0.0207 | — |
| fixed | 0.0000 | 1.0000 | 0 | 0.0000 | 0 | 0.0000 | — |

读数：

1. **现有面积加权实现过不了闸**：两种细分下 NGJres 分别为 0.49 / 1.46（阈值
   0.1 的 5 倍和 15 倍）。法线 dump 显示接缝节点法线被相邻大平面拉偏约
   0.6°（uniform）/ 1.85°（nonuniform），两个接缝偏的方向相反，形成一对
   亮度弯折；细分越不均匀越糟。
2. **卡之后（fixed，按面组分拆顶点法线、弧上取解析径向）全部归零**：
   NGJres = 0、LCEres = 0、corners = 0。
3. 朴素的「跨接缝法线二阶差分」不能直接用：正确的光滑圆角 rawD2 ≈ 1.0/r，
   减参考场是必须的。
4. `hardgap = 0` 同样不能放行——面积加权没有 C0 断裂却照样可见，说明只查
   法线连续性（常见做法）会漏检这类 C1 缺陷。

## 指标 B 的致盲演示（为什么只能让 A 当闸门）

把灯转到与平面 1 法线平行（接缝处于掠射，Lambert 项被 max(0,·) 钳到 0）：

```
uniform8    area: seam LCEres 0.0536（正常灯）→ 0.0052（掠射灯）
nonuniform8 area: seam LCEres 0.0207（正常灯）→ 0.0009（掠射灯）
            NGJres 不变：0.4906 / 1.4555
```

同一个坏法线场，换个灯位 B 就从不过闸变成过闸；A 与灯光无关，数值纹丝不动。

## 这两个代理在哪些模型上会失效

**NGJres（A）：**

- 需要「设计参考场」。解析圆/圆柱可以算 g_ref；任意扫描网格或雕刻模型没有
  解析参考时，退化方案是用邻域拟合圆曲率或改用跨接缝两侧的差分对称度，
  精度和可靠性都下降。
- 只管几何法线接缝。UV 接缝、切线空间不一致、法线贴图压缩造成的接缝它完全
  看不见，得在切线空间另设指标。
- 按顶点采样，检测尺度绑在网格分辨率上：亚像素级高频抖动会被顶点间平滑吃掉；
  反过来极粗细分下 g_ref 本身估计偏差大，阈值 0.1/r 要随段数放宽。
- 硬边（有意设计的折角）不是缺陷，但 A 会如实报大值——闸门需要面组/硬边标注
  把设计折角排除，而不是全局一刀切。

**LCEres（B）：**

- 依赖灯光与观察方向：上面的致盲演示就是实测；高光/粗糙度/环境贴图等真实
  BRDF 项没建模，金属材质上 B 与肉眼结论可能脱节。
- JND 阈值 0.01 是显示器 SDR、满量程亮度下的经验值，HDR、色调映射、
  曝光变化后要重新标定。
- 只在一条采样线上取点，采样线没压到的接缝会漏；要多条线或逐边扫描，
  成本随面数线性涨。
- 拐点检测对噪声敏感：量化噪声会凭空制造超阈值拐点，所以必须用残差形式，
  且上线前最好对输入法线做一次量化往返测试。

## 文件

- `src/seam.c` — 网格构造、三种法线方案、两套指标、致盲演示；
  文字化 include `../normal/src/normal.c`，测的就是生产实现；
- `tools/plot.py` — 纯标准库生成亮度曲线 SVG（`out/lum.svg`），无需 matplotlib；
- `out/lum.csv` — 400 点细采样亮度曲线。
