# hull

三维凸包，输入为网格顶点集合（凸包与面片连接关系无关），无外部依赖。

两个独立实现共享同一套面片池：

- **quickhull**：极点构造初始四面体，每轮取某面最远处外部点扩展，维护每面外部点集
- **incremental**：按输入顺序取前 4 个非共面点做种子，逐点插入，删除可见面、沿地平线补面

输出：凸包顶点（输入索引）、三角面片、体积。`make test` 跑自测：

1. 单四面体 — 凸包即自身，V = 1/6
2. 空心球（24×12 UV 球，266 顶点）— 所有顶点都在球面上，凸包保留全部顶点
3. 带凹坑立方体（23 顶点）— 凸包塌缩为 8 个角点，V = 8
4. 两实现交叉验证：顶点集合必须一致，体积必须一致；顶点发射顺序不同属算法路径差异
