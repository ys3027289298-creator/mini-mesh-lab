# trail

挥砍拖尾起点绑定：支撑函数取最远点，一次挥砍模拟给出起点偏差 / 可见长度 / 贴合度。

支撑函数：$h_S(\hat d)=\max_{p\in S}\langle p,\hat d\rangle$，$s_S(\hat d)=\arg\max$。
顶点网格取顶点 max；圆弧刃的面为 $c+r\hat u$（$\hat u$ 为 $\hat d$ 的面内投影方向，钳在弧张角内），一般不落在顶点上。

起点与可见长度：$r=|p_0-O|$，$L(p_0)=\min(r\Theta,\ B)$。起点外移 → $r$ 增大 → 预算 $B$ 封顶后覆盖角 $B/r$ 变小，两者互相牵制。定法：起点无条件取面支撑点（偏差归零），预算按 $B\ge r\Theta$ 定；预算不够则接受覆盖角 $\theta_{\text{cov}}=B/r$，不内移起点。

`make test` 跑自检。三种武器（直剑 / 弯刀 / 宽刃圆弧刃）各挥一次，输出九个数；宽刃贴合度最差时并列顶点最远点与面上最远点。
