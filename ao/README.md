# ao

环境光遮蔽（AO）烘焙实验，对比均匀半球采样与按遮挡距离重分配的重要性采样。
`make test` 跑三种凹陷深度的完整烘焙与自检。

## 模型

同一半径（1.0）的圆柱形凹陷，深度三档：0.5 / 1.25 / 2.5。地面 11×11 栅格、
坑底三圈、坑壁一圈，共 132 个烘焙点；求交用 Möller–Trumbore（双面，
`t_near=0.01` 自交保护，`t_max=1000`）。

## 采样器

- `uniform`：方向在半球立体角上均匀撒，遮挡率 = 命中射线占比。
- `distance`：每像素先撒 96 条 pilot 射线（半球均匀），按实测命中距离给
  每条 pilot 方向赋权——命中方向 `w ∝ 1/t`（近处密、远处疏），未命中方向
  权 1；单方向权做软上限 `p_cap=0.30`，再与 `alpha=0.20` 的经验均匀分布
  混合（保证没有方向拿到零质量）。192 条最终射线按 CDF 对 pilot 方向重采样，
  估计量按 `1/(N·q_j)` 加权保持无偏。密度函数完全由 pilot 实测的遮挡距离
  分布推出，6 个对数距离箱只用于直方图与密度诊断。
- ground truth：每像素 8192 条独立均匀射线。

## 输出（三组九个数）

每档深度记录三个数：遮蔽值五箱直方图（占比）、死黑像素占比（遮蔽 ≥ 0.95）、
平均遮蔽值；并附相对 GT 的 MAE。最近一次运行（distance 采样器）：

| 深度 | 死黑占比 | 平均遮蔽 | 直方图 [0,.2,.4,.6,.8,1] |
|---|---|---|---|
| 0.50 | 0.023 | 0.148 | 0.758,0.000,0.136,0.076,0.030 |
| 1.25 | 0.015 | 0.192 | 0.758,0.000,0.008,0.129,0.106 |
| 2.50 | 0.045 | 0.217 | 0.758,0.000,0.000,0.030,0.212 |

三档均值与 GT（0.141 / 0.194 / 0.218）偏差均在 0.01 内，估计无偏。

## 截断诊断

最深档始终把「最近遮挡距离」与「采样密度上限」并列打印；死黑占比 ≥ 0.10
时 `triggered=1`。自检中的对照实验把自交保护抬到 `5·t_near=0.05`（超过实测
最近命中 0.034），验证极近处遮挡确实会被截断（`near_truncation_would_cut`）。
