# triangulate

`make test` 跑耳切自检与三档长宽比实验。

耳的合格条件除凸角、无其他顶点落入三角形外，再检查长宽比：

```text
aspect = longest_edge / altitude_to_longest_edge
       = longest_edge² / (2 · area)
gate   = mean_edge² / (2 · target_min_area)
```

全局 `mean_edge` 是当前多边形的平均边长。没有合格耳朵时，不平切，改沿最均衡的内部对角线分割两个子环后递归。

内置三个 7 顶点凹多边形，包围盒长宽比分别约为 2、8、32；最细长一组保留一个边长约 `2e-4` 的浅凸尖。程序输出三角形数、最小面积、退化三角形数，并在最细长组出现退化三角形时并列打印该三角形的局部边长、全局门限和按局部最长边推出的门限。

## 实测三组九个数

参数：`target_min_area = 1e-2`，`area < 1e-8` 计为退化三角形。

| 多边形长宽比 | 三角形数 | 最小面积 | 退化三角形数 | 分割次数 |
|---:|---:|---:|---:|---:|
| ~2  | 5 | `4.990001e-05` | 0 | 1 |
| ~8  | 5 | `4.960001e-05` | 0 | 1 |
| ~32 | 5 | `1.999999999e-11` | 1 | 0 |

最细长组的退化尖耳仍通过了全局门限，条件诊断成立：

```text
local_edges          = 1.000002e-4, 1.000002e-4, 2.000000e-4
bad_aspect           = 1000.0000005
global_mean_edge     = 9.428571429
global_gate          = 4444.897959
local_gate(longest)  = 2.000000e-6
```

该组的平均边长被 16、32 单位的长边抬高，而肇事耳朵的局部最长边只有 `2e-4`，所以全局门限比局部尺度应得的门限宽约 `2.2e9` 倍。紧凑和中长两组中 `AR=1000` 的尖耳过不了各自的全局门限，算法转入对角线分割，把最小面积从硬切时的约 `2e-11` 提高到约 `5e-5`。
