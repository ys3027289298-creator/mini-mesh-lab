# bake

曲率感知外壳偏移的射线烘焙模拟。`make test` 跑自检并输出三档曲率 × 三项指标。

## 模型

低模为固定弦长的弧形条带，三档只改曲率半径（R=10/4/2），二面角随曲率增大；
高模是同弧、段数 ×6、沿凹侧内缩 `GAP` 的密网格。烘焙射线从低模表面沿面积加权
顶点法线发出，先命中低模相邻面片即记为自遮挡（无效像素），否则在 `BAKE_D`
内命中高模为有效。

## 外壳偏移

逐顶点先由相邻三列顶点的外接圆估计曲率半径 R，再取

```
d(v) = min(BAKE_D, SIGMA * R)
```

`SIGMA=0.25` 是穿透保护系数：曲率大（R 小）处偏移自动缩小，且恒小于高模间距，
不会穿过高模。

## 指标

| 指标 | 定义 |
|---|---|
| 接缝法线差 | 每条内部接缝两侧面法线夹角（度）的均值 |
| 暗线宽度 | 接缝两侧离缝最远的无效样本距离之和，按 `IMG_PX` 像素/弦长换算 |
| 有效像素占比 | 高模命中且未被低模自遮挡的采样点比例 |

零偏移基线随表一起打印作对照。若高曲率档有效占比相对最好档跌幅最大，
自动逐顶点并列打印该档的曲率半径与实际偏移量。
