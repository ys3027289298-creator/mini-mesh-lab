# simplify

碰撞网格边折叠简化 + 凸边顶点锁点实验。`make test` 跑自检并打印两条前沿曲线、
按目标简化率反解的锁点比例、三组台阶的主实验与角度-only 对照、以及最高台阶的
二面角/相邻面片尺寸并列诊断表。

## 要解决的问题

碰撞体简化后凸边被磨圆，角色在台阶边缘跌落。简化时锁住凸边顶点可保形，但锁太多
简化率上不去、锁太少台阶保不住。锁哪些由两个互相牵制的指标共同决定：

- **二面角**：边的尖锐度（90° 台阶棱 vs 共面 0°）
- **相邻面片尺寸**：大 riser/tread 交汇处被切掉后丢失的支撑更多

## 模型与方法

- 10 级台阶的 2D 行走轮廓沿宽度挤出成三角网格，每段 3 细分；轮廓 67 点 / 134 顶点 /
  132 三角面。凸角是台阶外棱，凹角是内棱，末级之后加两段 landing 收口。
- **锁点策略（gate-then-rank）**：二面角作门控，先花完最锐的角度档；同一角度档内
  完全按相邻面片尺寸排序，把锁给最大的 riser/tread 交汇。角度-only 对照组在同档内
  只按顶点索引破同分，不含任何尺寸信息。只有台阶棱点（凸+凹）是锁候选。
- **简化**：折线贪心折叠，代价为顶点到两存活邻点连线的垂直偏差；锁点阻止其关联折叠。
- **跌落判定**：在每级踏面中点查询简化后表面的上包络支撑高度，损失超过 δ=0.30 记一次。
- 只锁凸点不够：凹点塌掉后踏面变成两级凸点间的斜坡，角色仍会滑下，因此凸、凹棱点
  竞争同一锁点预算。

## 关键结论（见 `make test` 输出）

- 锁点比例 p 与最大高度损失 L(p)、可达简化率 Rmax(p) 的对应关系在 frontier_sweep 表。
- 目标简化率 0.75 反解出 k*=8 个轮廓锁点（16 个 3D 锁点，p*≈0.119）。
- 同预算下三组各 4 个数（锁点数、高度损失、实际简化率、跌落次数），共 12 个数。
  最高台阶：角度+尺寸策略跌落 1 次，角度-only 跌落 6 次。
- 诊断表把每个凸棱的二面角与相邻面片尺寸并列：所有可被角度看到的棱都是 90°，
  角度无差异、尺寸才有区分度；末级凸棱与 landing 共面（二面角 0°），任何纯角度
  规则都看不到它——这正是「只按二面角定锁点」的失效模式。
