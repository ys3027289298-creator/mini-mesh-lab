# lod

两级 LOD 滞回（hysteresis）切换仿真。`make test` 跑自检并打印全部指标，
`make csv` 导出 `--csv` 机器可读格式。

## 宽度怎么定（两条依据联立）

两级几何误差 `e_f < e_c`，屏幕误差 `SSE(e,d)=G·e/d`，门限 τ（像素），
名义切换距离 `d₀ = G·e_c/τ`。

1. **宽度是两级误差的函数（像素域门限差 w）**。切换瞬间的画面跳变
   `Δp₀ = τ·(1 − e_f/e_c)`。测量噪声 `σ_p(d)=√(σ₀²+(u·SSE)²)`，
   相机微抖 `A_j`：

   ```
   w_floor = 2·(A_j + k·σ_p(d₀))          # 防闪地板
   w = min( T_max·ṗ , max(w_floor, γ·Δp₀) )
   ```

   宽度由"误差跳变项 γ·Δp₀"和"噪声地板"取大，再受延迟预算与往返行程
   可达性封顶。门限差随 `(e_f,e_c)` 走；固定比例门限差（策略 A 的
   `W_FIX`）不随误差走，是对照组。
2. **宽度带来的切换延迟**。边界处 `ṗ = τ·v/d₀`，故
   `T = w/ṗ = w·d₀/(τ·v)`（帧）。两条一起定宽：先取满足防闪地板的
   最小 w，再校验 `T ≤ T_max`，且上边缘必须在往返行程的 SSE 峰值以内。

## 实验设置

- 三种误差模型：误差比 r = 2 / 4 / 8，对应 d₀ = 60 / 240 / 960
- 每档相对测量不确定性 `u_rel` = 0.04 / 0.10 / 0.22（粗糙误差元数据
  自带更大不确定性）
- 相机以固定世界速度 v=4 做一次 d₀±80% 的往返移动；每模型 32 个噪声
  seed，指标取均值
- 策略 A：三档共用折中固定宽度 4px；策略 B：宽度按上述误差公式分层
- 每档四指标：切换次数、闪烁帧数（反向 LOD 连续段 ≤5 帧的帧数）、
  切换延迟（相对无噪声理想穿越点的帧偏差）、画面差异（切换瞬间
  两级 SSE 差，px）

## 结论

固定折中宽度下，误差最大的 M3 同时具备最长延迟（77 帧）和最多闪烁
（86.8 帧/往返，平均 58.9 次切换）——宽度取了折中但没有按误差分层：
对 M1 偏宽（无谓延迟）、对 M3 远窄于其 3σ 噪声地板（23.6px），噪声
反复打穿门限。分层后 M3 闪烁被压到 0.22 帧（降幅 99.7%），代价是
延迟升到 61 帧（M3 本就是远处慢变档，该延迟在预算内）；M1/M2 保持
零闪烁且延迟与各自误差尺度匹配。
