# lod

带 UV 边界锁定的边折叠 + 位置焊接简化，`make test` 跑自检与三档边距实验。

## 问题

LOD 用单索引流按 3D 位置合并顶点（位置与 UV 共用索引，同 `welded/`）。
UV 接缝上两个顶点 3D 重合、UV 分属不同 UV 岛；合并后角点被重映射到存活
顶点，连带采用它的 UV。两类越界由此产生：

- **接缝焊接**：一次焊接的 UV 跳跃跨过整个岛间隙，相邻三角形 UV 直接覆盖
  背景纹素；
- **外边框折叠**：边界顶点并入内部顶点后，相邻 UV 三角形变形，越过岛边距
  采样到背景。

近处观察时贴图越过模型边界露出背景，即本模块要消除的现象。

## 锁定判定（边距 × 纹理尺寸，边距越小越要锁）

1. 按 3D 位置键建立边记录。只被一个面引用的是外边框；两侧 UV 对不一致的
   是内部 UV 接缝。
2. 对每个边界顶点几何量算外扩边距 `margin_tex`（纹素）：UV 空间内到纹理
   边框线、或到非邻接 UV 边界线段（岛间隙/对侧岛边沿）的最近距离 × 纹理
   尺寸。
3. 一步折叠的门限 `d_tex` = 平均最短 3D 邻边 × 基准纹素密度。基准密度固定
   在最宽档打包，使门限在三档间恒定（本实验 = 4.00 纹素），边距成为锁定数
   的唯一变量。
4. 规则：
   - **内部接缝顶点无条件锁**：其焊接跳跃等于整个岛间隙，任何外扩边距都吸收
     不了；
   - **外边框顶点**：`margin_tex <= d_tex` 即锁。边距越小，被锁边框顶点越多。

## 越界度量

绕序无关的软件光栅化（按三角形有符号面积选符号）把简化后网格的 UV 三角形
覆盖到像素网格，统计落在原始岛标签图背景（label=0）上的像素数。

## 实验

同一 8×4 网格面片（64 面），中列复制顶点形成内部接缝，两 UV 岛按三档边距
布局（外边距/岛间距，纹素）：wide 8/16、medium 4/6、narrow 1/2。每档记录
被锁顶点数（接缝+外边框）、贴图越界像素数、简化后面数（目标 32 面），并附
关闭全部锁定的对照组复现原始越界。

九个数（locked, bleed, faces）：

| 档位 | 外距/间隙 | 门限 | 锁定(缝+框) | 越界 | 面数 | 无锁越界 |
|---|---|---|---|---|---|---|
| wide | 8/16 | 4.00 | 26 (10+16) | 0 | 31 | 768 |
| medium | 4/6 | 4.00 | 32 (10+22) | 0 | 32 | 336 |
| narrow | 1/2 | 4.00 | 32 (10+22) | 0 | 32 | 124 |

锁定后三档越界均为 0；无锁对照组越界随间隙收窄而减少（间隙越小可覆盖的
背景越少），但始终 > 0，复现了原始 bug。

若 narrow 档仍有越界像素（说明锁定漏了 UV 接缝），程序逐条输出每条接缝的
边距、焊接跳跃与门限并列对照，并标 `locked` / `MISSED`。把锁定临时关掉即可
验证该诊断分支。
