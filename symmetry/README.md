# symmetry

镜像对称检测：镜像平面由**顶点质心 + 协方差主轴（PCA）**确定，匹配容差由
**最近邻间距的中位数（顶点密度统计量）**缩放得到。

`make test` 构建并跑自检 + 三个对称程度不同的模型实验，输出：

- 每个模型的对称顶点对数、中线重叠面数（清理前）、最大镜像偏差；
- 重叠面“清理前 / 仅焊接后 / 焊接+去重后”并列计数；
- 包围盒中心与质心+PCA 平面偏移的对照；
- 末尾 `===JSON===` 段为结构化结果，`all_ok=1` 表示自检全过。

顺序固定为 **原始网格检测 → 焊接 → 去重面 → 清理后复核**；不能先清理再检测，
否则重叠面会被清成 0 而掩盖合并缺陷。完整实验记录见
[`../artifacts/symmetry_results.md`](../artifacts/symmetry_results.md)。
