# interrupt

可中断的批处理网格管线：焊接 → 面积加权顶点法线，包围盒随焊接同步维护。

## 批次边界与原子性

取消是协作式的：`checkpoint()` 是唯一的取消点，每处理完一批调用一次，
批处理过程中不检查标志。每个批次在私有暂存区完成计算，边界处一次性
发布，因此中断后暴露的状态永远自洽，且恢复后与一次跑完的结果完全相同。

| 步骤 | 批次边界 | 原子提交方式 |
|---|---|---|
| 顶点焊接 + bbox | 每 `VBATCH` 个输入顶点 | `map[]`/`uniq[]`/`box` 在批内同步推进，边界才检查取消 |
| 面片重映射 | 每 `FBATCH` 个输入面 | 退化面在暂存区剔除，存活面整体追加到 `f[]`，再更新 `ncommitted` |
| 法线累加 | 每 `FBATCH` 个已提交面 | 只写私有 `acc[]`，输出 `nrm[]` 保持全零、发布门保持关 |
| 法线归一化 | 不可中断的单步 | 全部顶点算完后一次性打开 `normals_published` 门 |

关键不变量（任何可观察状态都必须满足，由 `validate()` 全量检查）：

- `map[]` 前缀全部指向焊接集合内、位置相等的顶点；焊接顶点两两不同。
- 已提交面片全部在焊接下标范围内且非退化。
- bbox 恰好等于已处理顶点前缀的 AABB。
- 法线门未开时 `nrm[]` 必须全零；门一旦打开，每个顶点要么是单位法线，
  要么被计入零长度累加器 `bad`——不允许一半有法线一半没有。

## 测试

`make test`：

1. 无中断基准运行，与独立参考实现逐顶点/逐面/逐法线比对；
2. **遍历每一个批次边界**取消一次（确定性全覆盖）；
3. **100 次随机时刻取消**，含二次取消和真实 `SIGINT` 投递，每次中断后
   全量校验状态自洽，再恢复并要求结果与参考实现一致；
4. 首个批次开始前取消标志已置位的场景。

`make fault-test`：三个故障注入构建，各自只破坏一个步骤的原子性。
校验器必须在某个取消点抓到并**报出具体步骤名**（`weld` / `normal` / `bbox`），
抓不到或报错步骤名不对则测试失败——证明校验器确实能定位原子性缺口，
而不是只会让干净代码通过。
