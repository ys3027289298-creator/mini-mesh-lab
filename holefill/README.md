# holefill

填洞绕向 + 面积合理性双判据自测。`make test` 跑自检。

## 判据一：绕向跟边界环，不跟世界上方

边界边取它在邻接三角面绕向中的方向（无反向配对的有向边），首尾串成有向边界环 `L`。网格按"外侧看 CCW"绕制时，该有向环的符号法向

```
n_loop = norm( Σ cross(p_i, p_{i+1}) )      // Newell
       与 norm( Σ cross(e_i, e_{i+1}) )      // 相邻边叉积和，同号
```

指向**内侧**，所以扇形候选三角形 `(center, L[i], L[i+1])` 在
`dot(n_tri, -n_loop) < 0` 时交换后两个顶点。整个判定只使用环自身的叉积
符号；模型整体旋转时所有向量一起旋转，结论不变，不出现 `(0,0,1)`。

## 判据二：填补面积 / 洞口投影面积

```
A_fill = Σ 0.5 |cross(b-a, c-a)|           // 新增三角面面积和
A_proj = 0.5 |Σ cross(p_i, p_{i+1})|       // 环 Newell 幅值之半
r = A_fill / A_proj                         // 平面质心扇形 r ≈ 1
```

`r > 1.5` 判失败：绕向即使全对， apex 伸出洞口 / 鼓包也会被拦下
（自测里 h=2 的 balloon：绕向 1.000，r≈2.52，面积判据拒绝）。

## 三个模型

同一个"六边形洞口（内径 1）+ 六边形法兰（外径 2，12 面）"，用正交基
`u×v=n` 摆成三档洞口朝向：朝上 `n=(0,0,+1)`、朝侧 `n=(+1,0,0)`、
朝下 `n=(0,0,-1)`。各填一次（质心 + 6 面扇形）。

指标口径：

- `dir`：新增面中几何法向与真值 `n` 同向的比例；
- `out_patch`：填补片顶点（环 6 + 中心 1 = 7）按**仅填补面**面积加权
  法向统计，`dot(n_v,n)>0` 的顶点数；
- `black`：128×128 正交软件渲染（相机/头灯都在该洞口自己的外侧并正视洞口，
  纯 Lambert、无环境光，故黑色只表示绕向反、法向朝内，与"朝下照不到世界光"
  无关），洞口 ROI（半径 0.80 的内切圆盘，1804 像素）内亮度 < 40 的像素数，
  朝内法向 `dot<0` 光照为 0，正好纯黑；
- `area_r`：上面的面积比。

## 固定参考方向 bug 的复现与诊断

程序另跑一版旧策略 `ORIENT_FIXED_UP`：
`dot(n_tri, (0,0,1)) < 0` 就翻转。结果：

| 洞口 | n·ref | dir | out(/7) | black/ROI | area_r |
|---|---:|---:|---:|---:|---:|
| up   | +1 | 1.000 | 7 | 0/1804 | 1.0000 |
| side |  0 | 0.000 | 0 | 1804/1804 | 1.0000 |
| down | -1 | 0.000 | 0 | 1804/1804 | 1.0000 |

朝下洞口全黑、面积比却正常（1.0000），正是"绕向判定用了固定参考方向"
的签名。三档洞口法线与参考方向并列：

| 档位 | 洞口法线 n | 固定参考 r | n·r | 夹角 | 固定参考判定 |
|---|---|---|---:|---:|---|
| 朝上 | (0,0,+1) | (0,0,1) | +1 | 0° | 碰巧正确 |
| 朝侧 | (+1,0,0) | (0,0,1) | 0 | 90° | 无信号，落入不翻转分支 → 反 |
| 朝下 | (0,0,-1) | (0,0,1) | -1 | 180° | 符号整个反掉 → 全黑 |

注意：全网格面积加权法线会在边界环上掩盖翻转——buggy 版全网格仍有
12/13 朝外（只有扇形中心朝内，环顶点被法兰面权重拉回），但填补片口径
为 0/7、渲染为 1804/1804 全黑。
