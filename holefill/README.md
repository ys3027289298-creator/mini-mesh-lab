# holefill

把边界洞投影到最佳拟合平面，按环的**凹度**决定填补方式，再按与边界相反的绕向缝回去。

- `concavity = 1 - area / hull_area`（0 = 凸环，越接近 1 越凹）。
- 凸环，或凹度不足半个步长：整环一次三角化（扇形），不加分割点。
- 凹环：分块数 `k = 1 + min(reflex, round(concavity / 0.08))`，
  从一个“能看到最多顶点”的凹顶点（根）出发，按等弧长放 `k-1` 个分割点，
  每块是“根 + 一段弧”，逐块三角化；某档放不下时退到更少的分块。
- 每块三角化后统计补片自交；把补片反向拼回去，使每条边恰被两个面以相反方向使用。

自检覆盖：闭环、无重复边、绕向一致、补片自交为 0、非平面边界（z 抖动）、
两个洞逐个补，以及“按周长比例算分块数”的对照（中洞和大洞都会自交）。

`make test` 跑自检，并打印三组摘要：
`fill_tris / self_int / nonmanifold_edges`，以及各环的凹度与两种分块数。
