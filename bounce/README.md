# bounce

内角（两垂直墙）碰撞响应，`make test` 跑自检与三档速度撞击实验。

## 两条物理约束

1. **恢复量按入射速度与接触面法线计算**：`e = e0 + k·|v·n|`，
   由法向入射分量决定，不再使用固定弹性系数。
2. **回弹速度不超过入射速度**：法向回弹量 `min(e·|vn|, |vn|)`，
   截断后沿反射方向重建速度（`respond_fixed`），而不是丢掉法向分量。

接触帧数门槛 `MIN_CONTACT=2`：不足两帧的接触只做位置投影、不改速度，
不触发完整回弹。

## 对照基线

`respond_naive` 复现 bug：上限触发时直接抹掉法向分量而不做方向修正，
高速撞击时角色持续重新穿透、卡在角落。

## 输出

两种策略各跑低/中/高三档入射速度，各记录三个数（共九个数 ×2）：

- `ratio`：回弹速率 / 入射速率
- `stuck`：卡住帧数（接触且法向速度为零的帧，上限 30）
- `angle_deg`：回弹方向与接触面法线的夹角

若高速档卡住帧数最多，打印 `clamp_table`，并列三档入射速度、
截断前法向速度（`vn_pre`）、上限（`cap`）与截断后法向速度（`vn_post`）。
