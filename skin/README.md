# skin

线性混合蒙皮（LBS）、权重归一化、肘部缩杆复现与自检。`make test` 跑自检。

## 关系式推导

实时管线的 LBS 不做齐次除法，第 j 个顶点（权重和 `s_j = Σ_i w_ij`）输出

```
q_j = Σ_i w_ij · T_i · p_j
```

把归一化后的权重记作 `w'_ij = w_ij / s_j`，归一化输出

```
q'_j = Σ_i w'_ij · T_i · p_j
```

两者逐项相除即得

```
q_j = s_j · q'_j
```

即**未归一化输出恒等于归一化输出乘以权重和**，与姿势无关。本实验室里骨骼
变换是纯线性矩阵（绕原点的旋转），因此就是以原点为中心、系数 `s_j` 的整体
缩放；带平移的一般仿射骨骼时同样有 `q = s·q'`（仿射项可直接并入求和，
`q = s·q'` 对任意仿射 T_i 恒成立），只是缩放中心变为
`c = Σ_i w_ij T_i` 的平移部分 / (1 − s_j)。

若环上所有顶点的 s 相同（本实验 s = 0.92），缩放对横截面是均匀的：

- 环周长 `P = s · P'`，周长相对收缩量 `ΔP/P' = 1 − s`；
- 顶点到骨骼轴的平均距离 `d̄ = s · d̄'`，`Δd̄/d̄' = 1 − s`。

这就是肘部"细杆"的直接来源：肘部顶点权重和最小，离关节越远的区域 s 越接近
1，视觉上就表现为肘处局部内缩。

## 归一化

```
w_ij ← w_ij / Σ_k w_kj
```

归一后 s ≡ 1，`q = q'`，缩杆消失。

## 截断上限

每条顶点只保留权重最大的 K 条影响（如 K = 4）。若截断后不重算，保留权重和
`s_keep < 1`，同一公式立刻把缩杆带回来；正确做法是截断后对保留的 K 条权重
再除一次 `s_keep`。自检中肘部顶点实际有 7 条影响，截到 4 条后
`s_keep = 0.80 + 3×0.02 = 0.86`，90° 姿势周长只剩静止姿态的 0.86。

## 实验夹具

两段臂：骨骼 0 为上臂（恒等），骨骼 1..7 为前臂族，共享绕肘关节的旋转
Rz(θ)。肘部截面为 12 顶点、半径 0.5 的圆环，权重 0.80 + 6×0.02 = 0.92。
因为整个环只受同一刚性变换的骨骼族驱动，归一化后环随前臂刚性转动，排除了
经典 LBS 在混合边界上固有的 `cos(θ/2)` 糖果纸效应，使任何残余收缩只能由
权重和解释。三种姿势 0°/45°/90°，每种量环周长与顶点到前臂轴的平均距离。
