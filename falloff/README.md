# falloff

软选择笔刷衰减曲线与网格密度的匹配。`make test` 跑实验并自检。

## 模型

笔刷半径 `R`，中心在原点，手填指数 `p`：

```
w(r) = 1 - (r/R)^p    (r < R)，否则 0
```

`w(0)=1`，中心拉满；`w(R)=0`，边缘断开。阶梯网格，间距 `h`，`k = h/R`。

## 两个条件（各是一条对 p 的不等式）

**A 顶点数** —— 权重 ≥ `W_MOVE` 的顶点数 ≥ `N_MIN`。等价于作用半径
`r_cut = R·W_MOVE^(1/p)` 至少够到第一圈轴向邻居 `r = h`：

```
W_MOVE^(1/p) >= k        =>        p >= pA = ln(W_MOVE) / ln(k)
```

**B 不出现台阶** —— 相邻顶点权重差 ≤ `G_MAX`。最大跳变出现在两端：

```
中心边  w(0)-w(h)   = k^p        <= G_MAX   =>  p >= pC = ln(G_MAX) / ln(k)
边缘边  w(R-h)-w(R) = 1-(1-k)^p  <= G_MAX   =>  p <= pR = ln(1-G_MAX) / ln(1-k)
```

B 是一段闭区间 `[pC, pR]`；两者相交当且仅当 `k < G_MAX`。

可用区间 = `[max(pA, pC), pR]`。

## 三组实测（R=1, W_MOVE=0.5, N_MIN=5, G_MAX=0.3, p=2）

| 网格 | h | 受影响顶点数 | 边缘权重梯度 | 台阶可感区域面积 |
|---|---|---|---|---|
| coarse | 0.500 | 9 | 0.7500 | 3.0000 |
| medium | 0.250 | 25 | 0.4375 | 2.2500 |
| fine | 0.125 | 101 | 0.2344 | 0.0000 |

受影响的顶点数按 `w >= 0.5` 统计；边缘梯度取四邻域相邻顶点的最大权重差；
台阶可感区域是四个角中最大相邻差超过 `G_MAX` 的网格单元的面积总和——
也就是能看出一级一级的地方面积。

## 指数区间

| 网格 | k | A: pA | B: pC | B: pR | 可用 |
|---|---|---|---|---|---|
| coarse | 0.500 | 1.000 | 1.737 | 0.515 | 空 |
| medium | 0.250 | 0.500 | 0.868 | 1.240 | [0.868, 1.240] |
| fine | 0.125 | 0.333 | 0.579 | 2.671 | [0.579, 2.671] |

手填的 p=2：fine 落在区间内；medium 偏高（梯度超限）；coarse 根本无解。

## 最稀疏那组：为什么为空

两条不等式的实际取值并列：

```
A 顶点数    p >= 1.000
B 边缘梯度  1.737 <= p <= 0.515
```

B 自身就是空集（`1.737 > 0.515`），不需要和 A 相交就已经无解。把 p 从 0
往上扫：B 在 `p = 0.515` 先破（边缘边跳变超过 0.30），此时 A 还没满足；
要到 `p = 1.000` 才凑够 5 个顶点，而那里 B 早已失效。

先破的是梯度条件。根因是 `k = 0.50 >= G_MAX = 0.30`：整体权重必须从约 1
落到 0，而半径内只有 `R/h = 2` 条边，每条边平均就得分走 0.5 的权重，
任何指数都摊不开。
