# symmetrize

左右对称化：先把镜像平面对齐到顶点分布的对称轴，再对两侧做平均。

`make test` 构建并跑自检 + 三个对称程度不同的角色面罩模型（strict / mid / low），
末尾 `all_ok=1` 表示自检全过（23 项）。`./symmetrize --json` 输出结构化结果。

## 做法

1. **拟合镜像平面**：顶点质心 `c` + 协方差矩阵 Jacobi 特征分解；三个特征轴各自做
   一次配对中分面偏移精修，取“镜像最近邻残差中位数”最小的轴为法向 `n`。
   偏移 `d` 用互配顶点对中点的中位数 `median(n·(p_i+p_j)/2)`，而不是直接 `n·c`：
   单侧突出物会把质心拉偏（low 上 `d=0.345` 而 `n·c=0.533`）。
2. **密度自适应带宽/容差**：最近邻间距中位数 `h`，处理带 `|n·p−d| ≤ 1.55h`，
   配对容差 `0.85h`，且要求互为最近镜像点。只处理带内、能配对的顶点；带外
   （角、单侧刺等“本该不对称”的部分）逐顶点保持不动。
3. **两侧平均（两条都做）**：
   - 位置 `p_i' = ½(p_i + R(p_j))`，`p_j' = R(p_i')`；
   - 法线在同一坐标系平均 `normalize(n_i + R_n(n_j))`，另一侧镜像回去。
   法线只平均不归一会缩短（low 上未归一平均长度最短到 `0.9564`，夹角越大缩得越短，
   即光照塌陷），重归一后长度恒为 1。

## 记录量

题面列了四个标量却写“三组九个数”。按计数，**九个数 = 3 模型 ×
(对称误差均值, 对称误差最大值, 法线夹角)**；被处理顶点占比是第四个、同时是末句
诊断用的量，单独成列。对称误差 = 顶点关于拟合平面镜像后到最近异己顶点的距离，
在处理带内统计；另对生成时已知的真实平面统计客观误差。

主三列取处理后残差（`artifacts/symmetrize_nine.csv`）：

| 模型 | 误差均值(后) | 误差最大(后) | 法线残余夹角° |
|---|---:|---:|---:|
| strict | 0.000000 | 0.000000 | 0.000000 |
| mid    | 0.033928 | 0.452745 | 0.000000 |
| low    | 0.187139 | 0.740174 | 0.000000 |

处理前的两侧法线夹角为 `1.7710 / 5.0410 / 22.6177°`，处理后互配法线严格互为镜像
（残余 0）。被处理顶点占比 `23.08% / 20.51% / 15.38%`，随对称程度递减。

## 诊断分支

`misaligned_signature(rows)` 实现题面判据：对称最低组占比为三组最高 **且** 其客观
（真实平面）误差无改善 → 判定镜像平面没对齐。对齐后的主表该值为 0；把三个模型强制
到错误的水平轴平面 `n=(0,1,0)` 后，该判据真实触发（low 占比并列最高 `20.51%`，客观
误差 `0.1035→0.1392` 反而变差），而它对错误平面自身的残差却 `0.1620→0.0816` 变好——
说明不能用错误平面的自洽残差判断对齐。此时程序把拟合平面方程 `A x+B y+C z=D` 与
顶点质心并列打印。另有构造的对照用例在自检里确定性地覆盖该判据的真假两个分支。
