# landing

倒地落地求解，`make test` 跑自检并输出三组坡度指标。

两步固定顺序：

1. `align_normal`：绕根骨骼原点旋转，使身体局部 +Z 对齐落点地形法线。
2. `clamp_root`：沿世界 +Z 平移根骨骼，使根骨骼最低点与地面间隙为 0。

顺序由 `run_landing()` 固定，并由 `Trace` 在运行时记录；穿透数据只作测量，不作顺序推断依据。
`order probe` 是仅用于自检的反序对照（先 clamp 后 align），不是落地路径。

模型：仰卧刚体，背部支撑面在根骨骼局部 z = -0.12 m；地形为 z = tan(坡度)·x 的平面。
坡度三组 0°/15°/35°。指标按全部身体顶点加根骨骼最低点统计：
穿透顶点（间隙 < -0.1 mm）、最大穿透深度、接触点（|间隙| ≤ 1 mm）。
