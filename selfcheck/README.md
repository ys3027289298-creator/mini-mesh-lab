# selfcheck

导入完成时跑的退化自检：模型导入后属性坏了往往过一阵才暴露，这里在导入出口处一次性筛四类退化。`make test` 跑自检。

## 四类判据与阈值推导

| # | 退化 | 判据 | 阈值怎么来的 |
|---|---|---|---|
| 1 | 顶点数为零 | 有限顶点数 `< 3` | 3 是构成一个面片的最小顶点数，不是调出来的旋钮。扫描显示零错误平台在 K∈[3,8]，取最保守端：K 再大就会把合法的极小网格（如单个三角形 nv=3）误报，这个风险在语料外 |
| 2 | 包围盒体积为零 | `min_extent / diag < 1e-4` | 下界：float32 相对误差 2⁻²³≈1.2e-7，导入变换链几次乘加后坐标噪声 ~1e-6，真正被压扁的模型该比值 ≤1e-6。上界：合法最薄件（钣金 0.1mm/100mm）~1e-3。1e-4 落在三个数量级的空档里 |
| 3 | 法线同向 | 平均合成长度 `R = \|Σn̂\|/N > 0.95` | R=1 即全部同向。限制在半角 α 锥内的分布有 R=(1+cos α)/2，0.95 对应 α≈26°——法线窄于此就不携带形状信息。合法最坏（60° 球冠 R≈0.82）与注入最坏（常量+1% 噪声 R≈0.99997）之间的空档中取点 |
| 4 | 孤立顶点 | 未被面片引用且离最近面 `> s/2` | **s 从顶点密度推出**：封闭网格 Euler 公式 F≈2V → 平均三角形面积 A/2V → 等边特征边长 s=√(2A/(√3·V))。游离顶点只有两种落点：在面上（d≈矢高≈0）或错一格（d≈s），s/2 是两层壳之间的中点，两侧 margin 都最大 |

## 误报/漏报权衡

`make test` 对四个旋钮各打印一张扫描表：阈值往紧调 MISS（漏报）升、往松调 FP（误报）升，表中 `zero-error plateau` 是两者都为零的平台，选点在平台内并标注 `<-- chosen`。实测平台：

- 顶点数 K∈[3, 8]，选 3（平台最保守端，语料外小网格的误报风险主导）
- 包围盒 τ∈[1e-4, 1e-3]，选 1e-4（靠松端：合法薄件的厚度分布比导入 bug 更不可控）
- 法线 R∈[0.85, 0.999]，选 0.95
- 孤立距离 k∈[0.2, 2]，选 0.5（≈ 实测间隙 [0.1, 3.67] 的几何中点）

## 验证设计

- **零误报**：6 个正常模型，刻意压每类的 FP 侧——3e-3 相对厚度的薄板（压判据 2）、60° 球冠 R≈0.82（压判据 3）、带面上/近面游离顶点的球（压判据 4）。
- **注入**：每类两种不同表现，缺一个不算抓到——
  1. 空缓冲 / 截断流（2 个有限顶点 + 其余 NaN）
  2. 缩放到点（恰好为零）/ 压扁到 1.4e-5（近零非零）
  3. 法线缓冲填同一常量 / 常量加 1% 抖动
  4. 远处垃圾点（~25·s）/ 近处游离点（3·s，只错几格）
- 注入模型断言「只触发自家那一类的位」，防止判据之间互相污染。
